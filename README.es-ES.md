## Estadísticas de la Liga del Golfo Pérsico en CSV
Este repositorio contiene datos completos y estructurados de los partidos de la Liga Profesional del Golfo Pérsico (Liga Premier de Irán). Los datos son útiles para analizar el rendimiento de los equipos, predecir los resultados de los partidos y extraer patrones estadísticos de la competencia de fútbol de mayor nivel de Irán.
## 📌 Introducción
La Liga Profesional del Golfo Pérsico es una de las ligas de fútbol más competitivas de Asia, con equipos de todo Irán. Este repositorio proporciona datos de partidos en formato CSV, lo que los hace fácilmente accesibles para investigadores, analistas deportivos y entusiastas del aprendizaje automático.
## 📂 Estructura del Repositorio
Este repositorio contiene varios archivos CSV relacionados con la Liga Profesional del Golfo Pérsico:
- Champions.csv: El campeón de la liga de cada temporada.
- LeagueTable.csv: La clasificación final de la liga para cada temporada.
- Results.csv: Resultados de partidos directos entre los equipos de la liga.
- Referees.csv: Información sobre los árbitros de la Liga Profesional del Golfo Pérsico.
- TopScorers.csv: El máximo goleador de cada temporada.
  
Estos conjuntos de datos incluyen estadísticas clave que permiten un análisis detallado del rendimiento de los equipos y jugadores a lo largo de diferentes temporadas.
## 🚀 Cómo Usar los Datos
Dado que este repositorio solo contiene archivos CSV, no se requieren dependencias o instalaciones adicionales. Puedes explorar y analizar los datos utilizando las siguientes herramientas:

1️⃣ Usando Excel o Google Sheets
Simplemente abre los archivos CSV en Microsoft Excel o Google Sheets para explorar y analizar los datos de forma visual.

2️⃣ Usando Python y Pandas
Puedes aprovechar Python y la biblioteca Pandas para el procesamiento y análisis de datos.

Ejemplo: Cargar el conjunto de datos en Python
```python
import pandas as pd

# Read the CSV file
df = pd.read_csv("LeagueTable.csv")

# Display the first five rows
print(df.head())
```
3️⃣ Usando SQL para Análisis de Datos
Si prefieres trabajar con bases de datos, puedes importar los archivos CSV a una base de datos SQLite y ejecutar consultas SQL para un análisis más estructurado.
